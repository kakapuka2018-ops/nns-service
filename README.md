# NNS Service — Multi-Master Android

Проект автосервиса с поддержкой нескольких мастеров.

## Быстрая проверка Android

Открой папку `android` в Android Studio.

Приложение использует API:

`http://10.0.2.2:8080`

Это адрес компьютера для Android Emulator. На реальном телефоне укажи IP компьютера/сервера в локальной сети, например `http://192.168.1.50:8080`, либо HTTPS-адрес сервера.

## Сборка APK через GitHub

В корне проекта уже есть GitHub Actions:

`.github/workflows/build-apk.yml`

После загрузки проекта в GitHub workflow автоматически собирает debug APK.

Инструкция: `GITHUB_BUILD.md`.

## Multi-master

- администратор видит всех клиентов;
- обычный мастер видит только своих клиентов;
- у клиента есть `master_id`;
- администратор может переносить клиента другому мастеру без удаления машин и истории;
- можно добавлять несколько мастеров.

## Сервер

`server/` — FastAPI API.

`docker-compose.yml` — запуск API с постоянным SQLite volume.

## Telegram-бот

`bot/bot.py` — сохранённая версия существующего NNS Service бота.

Перед боевым запуском бот должен быть подключён к той же базе/API, что и Android-клиент. Сейчас исходный бот сохранён отдельно, чтобы не ломать рабочую версию.
