# Сборка APK через GitHub — бесплатно для небольшого проекта

## 1. Создай репозиторий

На GitHub нажми **New repository**.

Например, имя:

`nns-service`

Можно сделать репозиторий Private.

## 2. Загрузи проект

Распакуй ZIP. В GitHub загрузи **содержимое папки `NNS_MultiMaster_Android`**, чтобы в корне репозитория были:

- `.github/`
- `android/`
- `server/`
- `bot/`
- `README.md`
- `docker-compose.yml`

## 3. Запусти сборку

После загрузки GitHub сам запустит:

**Actions → Build NNS Service APK**

Если автоматическая сборка не стартовала, открой workflow и нажми **Run workflow**.

## 4. Скачать APK

Открой завершившийся запуск workflow → внизу страницы **Artifacts** →

`nns-service-debug-apk`

Скачай ZIP, распакуй его и получишь:

`app-debug.apk`

Его можно передать на Android-телефон и установить.

## Важно

GitHub Actions предоставляет бесплатные квоты на публичные репозитории и ограниченные бесплатные минуты для приватных репозиториев. Для периодической сборки этого проекта обычно достаточно.

Для установки на свой телефон debug APK подходит для тестирования. Для публикации в Google Play позже лучше сделать release-сборку с собственной подписью.
